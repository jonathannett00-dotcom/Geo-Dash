# 🏇 Grand Prix Galopp

Ein Pferderennen-Wettspiel für den Monopoly-Abend – läuft komplett im Browser, ohne Server oder Installation.

## Spielen

`index.html` im Browser öffnen – oder das Repository über **GitHub Pages** veröffentlichen
(Settings → Pages → Branch auswählen), dann kann jeder online mitspielen.

## So funktioniert's

1. **Spiel einrichten:** Startbetrag und Währung festlegen und alle Spieler eintragen.
   Jeder Spieler bekommt denselben Startbetrag in seine Geldbörse.
2. **Monopoly-Geld einzahlen:** Was ihr bei Monopoly verdient, zahlt ihr mit **„+ Einzahlen“** in eure
   Wett-Geldbörse ein. Mit **„− Auszahlen“** geht Geld zurück ins Monopoly-Spiel.
3. **Wetten:** Spieler, Pferd, Wettart und Einsatz wählen.
   - **Sieg** – das Pferd muss gewinnen.
   - **Platz (Top 3)** – das Pferd muss unter die ersten drei kommen (niedrigere Quote).
4. **Rennen starten:** Countdown, animiertes Rennen mit Live-Kommentar und Zieleinlauf.
   Gewinne werden sofort mit Animation in die Geldbörsen gebucht.

Die Quoten werden vor jedem Rennen per Simulation aus Stärke und Ausdauer der Pferde berechnet.
Der Spielstand (Geldbörsen, Verlauf) wird im Browser gespeichert und bleibt beim Neuladen erhalten.
