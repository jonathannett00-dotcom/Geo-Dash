So geht’s

  1. 01 Fernseher öffnen „Neues Spiel starten“ auf dem großen Bildschirm. Dort erscheinen Raumcode und QR-Code.
  2. 02 Handy: Code eingeben Jeder gibt die vier Buchstaben ein oder scannt den QR-Code, wählt Namen und Farbe.
  3. 03 Spielen Gewürfelt, gemischt und gerechnet wird auf dem Server. Ihr spielt einfach.
Keine Anmeldung, keine App, keine Werbung.
Der Server startet, das dauert bis zu einer Minute.
